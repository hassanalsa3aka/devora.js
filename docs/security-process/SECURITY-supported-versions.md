## Supported versions

Devora.js is pre-1.0. Fixes go into the latest release only.

| Package | Supported |
|---|---|
| `@devorajs/core`, `@devorajs/cli` | latest 0.4.x |
| `@devorajs/adapter-node`, `@devorajs/adapter-vercel`, `@devorajs/adapter-netlify` | latest 0.3.x |
| `create-devora` | latest 0.4.x |
| `@devorajs/sekhem` (experimental engine, when published) | latest; experimental |

Node.js: the lines the project tests are listed on the Engines page of the documentation; Node 20 is end of life upstream.
